## Быстрый запуск из исходников

Установите Python **3.12 x64** с python.org. Распакуйте проект в доступную для записи папку. В PowerShell или cmd:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Если Windows показывает запрос брандмауэра во время входа, нужен только локальный callback на `127.0.0.1`; внешний сервер лаунчер не открывает. Не выключайте брандмауэр.

1. В «Настройки → Microsoft OAuth» задайте Client ID зарегистрированного публичного приложения и сохраните. Подробности — [OAUTH.md](docs/OAUTH.md).
2. На странице «Аккаунты» нажмите «Войти через Microsoft», завершите вход в системном браузере. Аккаунт должен иметь доступ к Minecraft Java Edition и настроенный Xbox-профиль.
3. В «Установка версий» получите список Mojang, выберите версию и установите её. Лаунчер скачает официальный клиент, библиотеки, ресурсы и runtime, проверит доступные SHA-1. Отмена оставляет установку незавершённой; повтор восстанавливает файлы.
4. Выберите созданный профиль на главной и нажмите «ИГРАТЬ».
5. Для Fabric сначала выберите Minecraft в «Модификации», получите совместимые загрузчики, затем установите выбранный loader. Моды добавляйте самостоятельно в папку `mods` этого профиля.

Без OAuth можно устанавливать и восстанавливать версии, создавать профили, настраивать Java, просматривать и архивировать миры. Запуск игры без авторизации не предусмотрен.

## Сборка Windows EXE

```bat
build.bat
```

Скрипт проверяет Python 3.12 x64, создаёт `.venv`, ставит зафиксированные зависимости, проверяет ресурсы и версию существующей `.venv`, выполняет pytest, запускает PyInstaller и smoke-test собранного приложения. Результат:

```text
dist/Zauch Launcher.exe
```

Это один файл с оконной подсистемой, без Python Console. Сборка требует интернет для PyPI и примерно 1–2 ГБ свободного места. Не запускайте `build.bat` с правами администратора. Подписывание Authenticode не настроено: для публичного распространения владелец проекта должен подписать сборку собственным сертификатом.

GitHub Actions: поместите содержимое этой папки в корень своего репозитория вместе со скрытой `.github`. Workflow **Build Windows launcher** запускается при push/PR и вручную. После успешной сборки скачайте артефакт **Zauch-Launcher-Windows-x64** на странице запуска workflow. Первый [Windows workflow](https://github.com/sohalegenda-wq/zauch-launcher/actions/runs/40070540317) уже выполнен успешно; исходники и EXE опубликованы как артефакты.

PyInstaller не делает Windows-сборки из Linux. Linux-файл, если он создан для проверки упаковки, не заменяет Windows `.exe`.

## Данные и профили

По умолчанию всё изменяемое хранится в `%LOCALAPPDATA%\ZauchLauncher`:

| Путь | Содержимое |
|---|---|
| `settings.json` | Параметры UI, загрузок, Client ID, активный профиль и аккаунт |
| `launcher.sqlite3` | Профили, состояния установок, имена аккаунтов, история запусков |
| `minecraft` | Общие `versions`, `libraries`, `assets`, `runtime` |
| `instances/<id>` | Отдельная папка профиля: миры, настройки, моды |
| `minecraft/.zauch/<version>.json` | Проверенные хеши установленных файлов |
| `cache` | Официальный список версий и загруженные скины |
| `logs`, `sessions` | Очищенные журналы и состояние процессов |
| `backups` | ZIP-копии миров |

Refresh token хранится **только в Windows Credential Manager**, сервис `ZauchLauncher.Microsoft`. Access token используется в памяти и в аргументах Java, как требует протокол Minecraft; процесс запускается без shell. Microsoft-пароли не запрашиваются самим приложением. Client Secret не используется. Выход удаляет локальный refresh token и запись аккаунта; для серверного отзыва сессий используйте настройки безопасности Microsoft.

Корневую папку общих игровых файлов можно изменить в настройках. Это влияет на **новые** установки; существующие профили сохраняют свой корень. Сменить папку мира можно в редакторе профиля; автоматического переноса файлов нет. Удаление профиля сохраняет его файлы. Удаление версии удаляет только её каталог `versions/<id>` и инвентарь; миры, моды, общие библиотеки и ассеты сохраняются.

Не указывайте в качестве папки игры каталог `versions`, `libraries` или другой внутренний каталог общих файлов. Профиль должен иметь свою папку, например `D:\Minecraft\Survival`.

## Производительность и Java

Минимальная/максимальная RAM ограничиваются 70% физической памяти компьютера. Zauch Performance задаёт пресеты до 2/4/8 ГБ с учётом этого предела. Параметры JVM не могут переопределять поля `-Xms`/`-Xmx`.

При установке runtime берётся из официального компонента `javaVersion.component`; требуемый major — из `javaVersion.majorVersion`. Для старых метаданных без этого поля применяется Java 8. Это историческая совместимость, а не гарантия поддержки каждого alpha/beta-клиента на Windows 11. Если Mojang не предоставляет нужный runtime для платформы, укажите совместимую Java x64 вручную и повторите восстановление. Пользовательская Java не заменяется без ведома пользователя; неправильный major или архитектура дают ошибку.

«Проверять все файлы перед запуском» проверяет сохранённый инвентарь SHA-1 и размеры. При повреждении нажмите «Восстановить». Установка и восстановление всегда проверяют доступные хеши из метаданных. Для отдельных Fabric Maven-артефактов API не предоставляет SHA-1: загрузка идёт по HTTPS, затем сохраняется локальный хеш для обнаружения последующих изменений. Это не подпись издателя.

## Загрузки и отмена

Проценты относятся к текущему этапу библиотеки/ресурсы/runtime. Скорость — реальное среднее количество сетевых байтов с начала операции; повторные попытки и сжатые Java-файлы входят в переданный объём. Суммарный размер установки заранее не придумывается. Файлы записываются во временный файл и заменяются после проверки. Пофайловое возобновление поддерживается; HTTP Range внутри незавершённого файла пока нет.

Работу координирует QThread. Установщик работает в дочернем процессе, чтобы отмена могла остановить зависший запрос. После отмены процесс получает сигнал; через 3 секунды при необходимости завершается принудительно. Статус `ready` устанавливается только после финальной проверки. Остаточные `.zauch.part` можно удалить через очистку кэша.

Сопровождение игры работает отдельно от UI. При закрытии лаунчера игра продолжает работу; её вывод и код завершения сохраняются. После повторного открытия лаунчера уже работающий процесс восстанавливается из `sessions`, если он ещё существует. Не создавайте резервную копию мира во время работы игры.

## Сеть

Необходимы HTTPS-доступы:

- `piston-meta.mojang.com`, `launchermeta.mojang.com` — метаданные клиента/runtime;
- `piston-data.mojang.com`, `launcher.mojang.com` — клиент/runtime;
- `libraries.minecraft.net`, `resources.download.minecraft.net`, `textures.minecraft.net` — библиотеки, ресурсы и скины;
- `meta.fabricmc.net`, `maven.fabricmc.net` — Fabric;
- `login.microsoftonline.com`, `user.auth.xboxlive.com`, `xsts.auth.xboxlive.com`, `api.minecraftservices.com` — Microsoft/Xbox/Minecraft;
- домены, на которые Microsoft перенаправляет интерактивный браузер при входе.

Проверка сетевых каталогов (не скачивает игру):

```bat
.venv\Scripts\python tools\network_check.py
```

Если сеть блокирует Mojang/Fabric, лаунчер показывает ошибку; сохранённый официальный список остаётся доступен. Токены и тело OAuth-ответов в журнал не выводятся. В локальной среде используйте корпоративные настройки прокси/CA; не отключайте TLS-проверку.

## Реализованный объём и ограничения

Реализованы Vanilla, Fabric, профили, Microsoft PKCE/state, refresh, системное хранилище, выбор и установка Java, реальная команда minecraft-launcher-lib, независимый процесс игры, ремонт, проверка файлов, история, резервные копии миров, две темы/акцента/оригинальных фоновых SVG, автозапуск Windows и сборка.

Quilt/NeoForge и каталог загрузки отдельных модов не заявляются. Автоматическое обновление самого лаунчера недоступно: не задан издатель, сервер подписанных релизов и ключ проверки. В UI это явно указано, переключателя фиктивного обновления нет. Сетевая установка и реальный запуск Minecraft требуют отдельного end-to-end прогона на Windows с корректным Client ID и лицензированным аккаунтом.

Скины загружаются явно кнопкой «Загрузить скин» из URL профиля Minecraft и показываются как настоящая текстура; 3D-просмотр не реализован. Изображения фона — оригинальные SVG, а не скриншоты Minecraft. Иконка Lucide загружена из официального репозитория с сохранением лицензии.

## Разработка и проверки

```bat
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
.venv\Scripts\python tools\check_resources.py
.venv\Scripts\python main.py --self-test smoke.json
```

Для headless проверки задайте `QT_QPA_PLATFORM=offscreen` и временный `ZAUCH_DATA_DIR`; smoke-test сохраняет настройки в указанном каталоге и создаёт PNG рядом с JSON-отчётом. В обычном использовании эти переменные не нужны. Сборочный скрипт задаёт их только в своём процессе. Unit-тесты используют явные тестовые данные, включая неигровые файлы; ни один такой файл не включён в игровые установки пользователя.

Архитектура: `core/` — сеть, Java, OAuth, SQLite, установка, сопровождение игры; `ui/` — нативные виджеты и QThread; `tools/` — ресурсы, smoke-test, диагностика; `tests/` — проверки; `.github/workflows/` — Windows CI.
